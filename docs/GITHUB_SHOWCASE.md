## Pinned Repository README Opening

SynapseHire is a startup-grade AI hiring simulation platform that brings live coding, video interviews, AI evaluation, anti-cheating telemetry, and recruiter analytics into one production-ready system.

Unlike a basic CRUD app, this project demonstrates:

- real-time distributed systems with Socket.IO and Redis
- WebRTC media workflows
- AI prompt/schema engineering
- secure authentication and session handling
- recruiter analytics and reporting
- Dockerized cloud deployment
- CI/CD and observability

## Demo Script

1. Sign up as a recruiter.
2. Create or open an interview.
3. Join the collaborative coding room.
4. Open the video interview room.
5. Trigger a monitoring event by switching tabs.
6. Open recruiter monitoring dashboard.
7. Run AI interview analysis.
8. View recruiter analytics dashboard.
9. Export interview reports as CSV.

I built SynapseHire, an AI-powered hiring simulation platform for live technical interviews.

It includes:

- Real-time collaborative Monaco coding editor
- WebRTC video interviews
- Tab/screen/face/audio monitoring
- AI interview scoring with OpenAI/Gemini
- Resume-job and GitHub profile analysis
- Recruiter analytics dashboards

- Docker, GitHub Actions, Nginx, PM2, AWS/Vercel deployment
